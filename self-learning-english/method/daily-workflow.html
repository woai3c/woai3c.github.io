每日训练流程 ​

核心流程 ​

听材料
→ 理解内容
→ 第一次复述
→ 检查错误
→ 提炼 3～5 个表达
→ 替换造句
→ 第二次复述
→ 隔天复习

每日执行方式（20～30 分钟） ​

第一阶段：听和理解（5～8 分钟） ​

  1. 选一段 1～3 分钟的材料（如《走遍美国》某一节）
  2. 先不看文本，听 1～2 遍，抓大意
  3. 遇到听不懂的地方，看文本确认
  4. 确保没有不认识的关键词

第二阶段：第一次复述（5 分钟） ​

  1. 关掉材料，用自己的话复述刚才听到的内容
  2. 可以录音，方便回听
  3. 不追求完美，先说出来

第三阶段：检查和提炼（5～8 分钟） ​

  1. 回听录音或回忆复述过程，找出问题：
    • 哪里卡住了？
    • 哪里用了中文思维？
    • 哪里时态搞错了？
    • 哪个词不确定？
  2. 从材料中提炼 3～5 个值得练习的表达
  3. 每个表达用自己的场景造 2～3 个替换句

第四阶段：第二次复述（5 分钟） ​

  1. 重新复述同一段内容
  2. 尝试主动使用刚刚提炼的表达
  3. 对比两次复述的差异

隔天复习 ​

  • 第二天花 3～5 分钟重新复述同一段内容
  • 检查重点表达是否还能主动使用
  • 一周后再复述一次，确认掌握程度

工作场景训练（可选，额外 15～20 分钟） ​

如果时间允许，可以在上述训练之外加入工作场景练习：

  • 周一/四：Stand-up 站会汇报
  • 周二/五：描述 Bug / 技术问题
  • 周三/六：技术讨论 / 确认需求
  • 周日：自由复习或休息

每个场景的训练方式：写下内容 → 脱稿说出来 → 录音 → 回听纠正 → 再录一遍。
