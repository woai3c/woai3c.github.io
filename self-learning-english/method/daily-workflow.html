每日训练流程 ​

当前阶段的材料 ​

  • B1 听力主线：British Council B1 Listening 的工作场景和 BBC Office English
  • A2 口语转化：925 English 和工作交流语言块，用于跟读、替换和角色扮演
  • 技术听力：VOA Technology Report 和有英文字幕的技术讲解
  • 真实材料：Developer Tea、Stack Overflow Podcast 和 Soft Skills Engineering
  • 输出：远程会议自救、站会、Bug、需求、技术解释、异步协作、项目介绍和面试

精听材料统一围绕实际工作交流。完整材料清单、使用顺序和手机收听方法见 听力材料。

《走遍美国》的历史练习记录继续保留，但不再作为当前主线。每天优先完成一段 B1 工作听力，再用 A2 难度的简单句完成脱稿输出。听力 B1 和口语 A2 分开判断， 不要求复述使用和原材料一样复杂的句子。

核心流程 ​

听材料
→ 理解内容
→ 第一次复述
→ 检查错误
→ 提炼 3～5 个表达
→ 替换造句
→ 第二次复述
→ 隔天复习

最低版：20～30 分钟 ​

第一阶段：听和理解（5～8 分钟） ​

  1. 选择一段 B1 工作材料；分级材料可以听完整一段，真实材料截取 3～5 分钟
  2. 先不看文本，听 1～2 遍，抓大意
  3. 遇到听不懂的地方，看文本确认
  4. 确保没有不认识的关键词

第二阶段：第一次复述（5 分钟） ​

  1. 关掉材料，用自己的话复述刚才听到的内容
  2. 可以录音，方便回听
  3. 不追求完美，先说出来

第三阶段：检查和提炼（5～8 分钟） ​

  1. 回听录音或回忆复述过程，找出问题：
    • 哪里卡住了？
    • 哪里用了中文思维？
    • 哪里时态搞错了？
    • 哪个词不确定？
  2. 从材料中提炼 3～5 个值得练习的表达
  3. 每个表达用自己的场景造 2～3 个替换句

第四阶段：第二次复述（5 分钟） ​

  1. 重新复述同一段内容
  2. 尝试主动使用刚刚提炼的表达
  3. 对比两次复述的差异

隔天复习 ​

  • 第二天花 3～5 分钟重新复述同一段内容
  • 检查重点表达是否还能主动使用
  • 一周后再复述一次，确认掌握程度

完整版：60～90 分钟 ​

时间充足时，在最低版之外增加以下内容：

  • 跟读 10～15 分钟：模仿当前材料的重音、停顿和连读
  • 职场短听力 10～15 分钟：从 British Council B1 或 BBC 选一段， 结束后用 3～5 句英语复述
  • 技术短听力 10～15 分钟：从 VOA 或带英文字幕的技术视频截取 1～3 分钟
  • A2 口语 15～20 分钟：把材料换成自己的项目，脱稿表达，检查后再说一遍
  • 词汇维护 5～10 分钟（可选）：只复习已有内容，不设每日新词数量

完整版不是每天必须完成的硬指标。忙时只做最低版，避免因为时间不足而完全中断。

工作场景轮换 ​

如果时间允许，可以在上述训练之外加入工作场景练习：

  • 周一：远程会议自救 / 听不清时确认
  • 周二：Stand-up / 异步进度汇报
  • 周三：描述 Bug / 排查技术问题
  • 周四：确认需求 / 讨论验收标准
  • 周五：解释代码、架构或数据流
  • 周六：项目介绍 / 远程面试 / Demo
  • 周日：复述本周最难的一段，或休息

每个场景的训练方式：写下内容 → 脱稿说出来 → 录音 → 回听纠正 → 再录一遍。

材料比例和切换计划 ​

  • 当前听力 B1：50% 分级职场英语、30% 清晰技术讲解、20% 真实材料
  • B1 稳定后：40% 分级职场英语、30% 技术讲解、30% B2 或真实材料
  • A2 材料主要用于跟读和口语自动化，不再承担主要听力挑战

精听材料必须带文本或字幕，内容要能迁移到实际工作，连续语言要占主要部分； 跟读材料要发音清晰、语速适中。影视、技术新闻和真实播客可以补充语感，但不能 代替会议对话。是否换阶段由实际训练表现决定，不机械地按日期切换。

听力和口语的级别标准 ​

当前听力约为 B1，口语约为 A2。听力使用 B1 新材料训练；口语继续使用简单句， 重点解决卡顿、组织顺序和回答追问，不提前追求复杂句。

听懂率按主要信息估算，不按听出的单词数量计算：能否说出主题、人物目的、 关键事实和最后结果。

  • A2 Listening： 短而清楚的日常和工作对话
  • B1 Listening： 电话、会议、采访以及清晰的日常或工作话题
  • B2 Listening： 更长的广播、访谈、演讲和包含复杂观点的熟悉话题

连续 5 段 B1 新材料达到以下标准，再把 B2 或真实材料提高到训练量的 30%：

  1. 第一遍不看文本能理解约 70% 的主要信息。
  2. 第二遍不看文本能理解约 80%。
  3. 配套理解题正确率达到 80%。
  4. 不看文本能用 3～5 句英语复述主题、关键事件和结果。

第一次听懂 50%～70% 的 B1 材料适合精听；低于 40% 时缩短片段或换一段更清楚 的 B1 材料。稳定达到 70% 以上时，每周加入一段 B2 试听，不一次性全部替换。

口语暂时不以复杂度升级，而检查下面四项：

  1. 能用简单完整的句子连续表达 60～90 秒。
  2. 能主动使用本轮选择的 3～5 个语言块。
  3. 能回答两个相关追问。
  4. 想不起复杂表达时会主动换成简单说法，而不是长时间沉默。

每四周固定测试 ​

测试条件保持一致，才能纵向比较：

  • 2 分钟自我介绍 + 3 分钟 stand-up + 5 分钟项目介绍
  • 听一段没听过的 2 分钟材料两遍，然后脱稿复述
  • 与 AI 或真人进行 10 分钟连续工作场景对话
  • 用 10 分钟写一封进度汇报或 Bug 描述

重点观察：沉默卡顿是否减少、能否说完整句、是否依赖中译英，以及能否听懂并 回答追问。四到八周没有变化时，调整材料难度或输出量。
