Day 3 · 函数是一等公民 ​

前言 ​

Python 函数是一等公民，可以赋值、传参与返回。它还有一套丰富的参数体系：位置参数、关键字参数、*args、**kwargs、keyword-only、positional-only……今天一次性搞清楚。

课程目标 ​

  • 掌握 Python 完整的参数声明体系
  • 熟练使用 lambda、map/filter/reduce（以及什么时候不该用它们）
  • 理解闭包与 nonlocal
  • 初步认识 functools 这个宝藏模块

阅读学习 ​

  • Python 官方教程 4.7：定义函数的更多方式
  • functools 官方文档（浏览即可）
  • 对照速览：
JSPython
剩余参数 ...args*args（元组）
没有对应物**kwargs（关键字参数字典）
默认参数 function f(a = 1)def f(a=1)（注意预备班的坑）
箭头函数 x => x * 2lambda x: x * 2（只能写单表达式！）
Array.prototype.reducefunctools.reduce（被刻意雪藏，推导式才是主流）
闭包直接改外层变量需要 nonlocal 声明

任务作业 ​

  1. 参数大师：实现一个函数签名：
python
def create_request(method, url, /, *, timeout=10, retry=3, **headers): ...

要求：method 和 url 只能位置传参（positional-only），timeout 和 retry 只能关键字传参（keyword-only），其余关键字参数全部进 headers。写几个合法/非法的调用示例验证你的理解。

  1. 手写 curry：不用任何库，实现 curry(f)，使得 curry(add)(1)(2)(3) == 6（函数可接收任意元数），理解函数如何被逐层包装与返回。

  2. 闭包计数器：

python
def make_counter():
    count = 0
    def inc():
        # 你的代码：让 count 正确累加
        ...
    return inc

分别用 nonlocal、列表包装、函数属性三种方式实现，说说各自的优劣。

  1. functools 实战：用 functools.lru_cache 给递归版斐波那契加速，对比加缓存前后的耗时；再用 functools.partial 固化出一个 power_of_2 = partial(pow, 2) 并解释 partial 的应用场景（提示：回调函数签名对齐）。

  2. lambda 的边界：尝试用 Python lambda 表达带多个分支的复杂逻辑，然后改写成 def，理解“Python 故意限制 lambda”背后的设计哲学。

自测问题 ​

  • *args 和 **kwargs 在函数定义和调用时分别扮演什么角色？
  • lambda 为什么不能包含语句（statement）？这个限制是缺陷还是设计？
  • nonlocal 和 global 的区别是什么？
  • functools.lru_cache 缓存的 key 是什么？被缓存函数的参数有什么要求？
  • Python 有基于参数签名的函数重载吗？通常用什么模式替代？
