Day 1 · 面向对象：class 与魔术方法 ​

前言 ​

你从 ES6 class 过来，会觉得 Python 的 class 似曾相识，但很快就会发现：Python 的 OOP 更"裸露"——没有真正的私有、一切皆协议、魔术方法（dunder method）控制着对象的一切行为。理解了魔术方法，你就理解了 Python 的设计哲学：数据模型优于语法糖。

课程目标 ​

  • 掌握 class 定义、继承、super()
  • 掌握常用魔术方法：__init__ __repr__ __eq__ __len__ __getitem__ 等
  • 熟练使用 @property、@staticmethod、@classmethod
  • 使用 @dataclass 消灭样板代码

阅读学习 ​

  • Python 官方教程第 9 章：类
  • Python 数据模型（魔术方法大全）（浏览）

任务作业 ​

  1. 实现一个"像列表"的类：写一个 Stack 类，支持 len(s)、s[i]、for x in s、x in s、print(s)，全部通过魔术方法实现。体会"实现协议即融入语言"。

  2. dataclass 实战：用 @dataclass 建模一个 User（含 name/email/age），要求：

    • age 有默认值 0
    • email 用 __post_init__ 做格式校验
    • 用 field(compare=False) 让排序只按 age
    • 尝试 frozen=True 体会不可变 dataclass

    然后反思：这个装饰器帮你省掉了哪些样板代码？

  3. property 重构：把一个暴露公共属性 celsius 的 Temperature 类，重构成不破坏调用方代码的 @property 版本（访问 .celsius 时动态计算自内部存储的开尔文值）。体会 Python 的"先公开、后属性化"重构自由。

  4. classmethod 工厂：给 User 增加 User.from_dict(data) 和 User.from_json(s) 两个工厂方法，用 @classmethod 实现。

自测问题 ​

  • __str__ 和 __repr__ 的区别是什么？只实现一个的话实现哪个？
  • Python 的 __private 双下划线属性真的私有吗？它是如何实现的（name mangling）？
  • Python 支持多继承，super() 的查找顺序遵循什么算法（MRO）？
  • dataclass 的 eq=True、order=True、frozen=True 分别生成哪些方法？
  • 为什么 Python 的实例方法要显式接收 self？调用时它是如何传入的？
