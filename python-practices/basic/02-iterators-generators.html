Day 2 · 迭代器与生成器 ​

前言 ​

Python 的迭代协议支撑着 for 循环与整个惰性计算生态：map、filter、zip、enumerate 返回的都是惰性迭代器。掌握迭代器与生成器，你就能写出内存占用 O(1) 的数据管道。

课程目标 ​

  • 理解迭代协议（__iter__ / __next__ / StopIteration）
  • 熟练使用生成器函数与生成器表达式
  • 掌握 itertools 常用工具
  • 理解 yield from 与生成器委托

阅读学习 ​

  • Python 官方教程 9.9：迭代器与生成器
  • itertools 官方文档（值得通读，都是宝）
  • 关键认知：
    • 列表推导式 [...] 立即求值，生成器表达式 (...) 惰性求值
    • 迭代器是一次性的——耗尽后再遍历就是空的
    • for 循环的本质就是迭代协议

任务作业 ​

  1. 手写迭代器：不用生成器语法，写一个纯类实现的 Countdown(n)，支持 for i in Countdown(3) 输出 3、2、1。要求实现 __iter__ 和 __next__，并在结束时正确抛出 StopIteration。

  2. 惰性文件流：写一个函数 read_large_log(path)，用生成器逐行读取一个 1GB 的日志文件（可以自己造一个），配合 yield 返回解析后的 dict。要求全程内存占用不随文件大小增长，并用 tracemalloc（标准库）或 psutil（需 uv add --dev psutil）验证（对比一次性 readlines() 的内存）。

  3. 生成器管道：构建一个 Unix 管道风格的数据处理链：

python
lines = read_large_log("app.log")
errors = (line for line in lines if "ERROR" in line)
parsed = (parse(line) for line in errors)
top5 = itertools.islice(parsed, 5)

体会每一层都是零成本的惰性包装，只有最终消费时才真正流动。

  1. itertools 挑战：不用显式循环，只用 itertools 完成：

    • 生成无限的斐波那契数列并取前 20 个（islice）
    • 对 [1, 2, 3] 生成所有长度为 2 的排列（permutations）和组合（combinations）
    • 把 [1,2,3,4,5,6,7] 按奇偶分组（groupby——注意它要求先排序的坑）

  2. 踩坑实验：gen = (x for x in range(3))，list(gen) 之后再 list(gen) 得到什么？写进笔记，时刻提醒自己。

自测问题 ​

  • iter() 和 next() 内置函数分别对应什么魔术方法？
  • 生成器函数被调用时，函数体立即执行吗？
  • yield from 解决了什么问题？
  • 为什么 groupby 要求输入已按分组键排序？
  • 生成器可以重启吗？想反复遍历一个惰性序列该怎么办？
