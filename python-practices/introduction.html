学园介绍 ​

这是一个什么样的学园 ​

Python 技术学园是一个帮助你自我成长、系统掌握 Python 的园地。它的教学法完全参考了百度 Web 前端技术学园（IFE）。

本学园从 Python 零基础出发，不设编程语言、技术栈或工作经验门槛。在这里，你会得到：

  • 对 Python 核心概念与语言特性的清晰讲解（缩进、GIL、可变默认参数、is vs ==……）
  • 有人给你精心挑选的阅读材料，而不是让你在搜索引擎里迷路
  • 有人给你设计从易到难的实战任务，让你每写一行代码都知道它的用武之地

我们的教学法（向 IFE 致敬） ​

实践驱动。 以实践任务的练习为学习的主要驱动，通过实践与知识的搭配，让你知道每一个知识点的用武之地。

先读后练。 每个任务都遵循 IFE 经典的页面结构：

  1. 前言 / 课程目标 —— 今天要学什么，为什么学
  2. 阅读学习 —— 精选的官方文档与优质文章，先建立概念
  3. 任务作业 —— 动手的实战任务，有明确的实现步骤和验收标准
  4. 自测问题 —— 不写代码，用嘴巴（或键盘）回答，检验概念是否真的掌握
  5. 总结 —— 固定的学习笔记模板，记录用时、收获与疑问
  6. 拓展阅读 —— 给学有余力的你
  7. 预告 —— 下一节学什么

建立知识连接。 课程会先讲清 Python 本身，并在适合的地方提供 JS/Node ↔ Python 对照表。这些对照是辅助材料，不是学习前提。

重视方法而非灌输。 我们希望你能够学习的不仅仅是知识，更希望你在这里找到、掌握自己的学习方法。一切的成长和进步一定依赖于你自己，也归功于你自己。

班级设置 ​

学园按难度分为五个班级，从易到难逐级通关：

  • 预备班 · 起跑准备：环境搭建与 Python 核心思维
  • 入门班 · 语言基础：语法、数据结构、函数、模块
  • 基础班 · 语言进阶：OOP、迭代器与生成器、装饰器、异常与 IO、包管理
  • 进阶班 · 工程能力：asyncio、并发模型、类型提示、FastAPI、pytest
  • 高级班 · Python 后端工程：ORM 与迁移、认证与安全、缓存与异步任务、可观测性、Docker 化、K8s 部署、毕业项目

学习建议 ​

  • 不要跳级：任务经过精心设计，后面的任务依赖前面建立的直觉
  • 动手 > 阅读：阅读材料是辅助，代码写够才算学会
  • 坚持记笔记：每个任务的"总结"环节请认真对待，它是 IFE 教学法的精髓
  • 允许犯错：在 Python 里踩坑是必经之路（比如可变默认参数），踩过才记得住
