开学第一课：一起来感受 Python 之美 ​

课程背景 ​

本课程从 Python 语言本身出发，通过循序渐进的阅读、实验和项目，一路学到 Python 后端工程。

课程目标 ​

  • 做好预备奔跑的姿势
  • 开始爱上 Python
  • 大概知道 Python 能做什么、为什么 AI 时代它是第一语言
  • 写下你学习 Python 的 Flag

Python 案例 ​

好的，我们开始吧。在写任何一行 Python 之前，先看看这个语言生态里那些美好的东西。依次浏览下面的项目（建议不要同时都打开）：

  • FastAPI —— 现代 Python Web 框架，自动生成 OpenAPI 文档，性能对标 Node.js
  • Rich —— 在终端里渲染出富文本、表格、进度条，体验 pip install rich 之后的终端美学
  • Textual —— 用 Python 写出漂亮的终端 UI（TUI）应用
  • Manim —— 3Blue1Brown 的数学动画引擎，那些惊艳的数学视频都是 Python 生成的
  • SQLAlchemy —— Python ORM 的事实标准，高级班的主角
  • Celery —— 成熟的分布式任务队列
  • httpie —— 比 curl 人性化十倍的 HTTP 客户端，纯 Python 实现

还有许多优秀的项目，不妨点进去亲自感受一下 Python 生态的魅力。

不妨在浏览器中专门建一个收藏夹目录，叫做 python-showcase，把上面这些项目都放进去，当以后想找灵感的时候，不妨多看看。

Python 背景知识 ​

初体验了 Python 生态，我们来系统地了解一下 Python 是什么、它的发展历史与设计哲学：

  • Python 官方教程（中文） —— 全站最重要的资料，没有之一
  • Python 之禅（PEP 20） —— 打开终端输入 python -c "import this" 也能看到
  • The History of Python —— Guido 亲自写的 Python 发展史
  • Python 是如何流行起来的
  • awesome-python —— Python 生态的全景地图

学习方法论 ​

在接下来的学习中，我们建议：

  1. 建立知识连接：先弄清每个概念在 Python 中的意义；如果你熟悉其他语言，再通过对照加深理解。
  2. 警惕经验陷阱：你以为一样的，往往不一样。比如 Python 的 == 和 is、列表作为默认参数的坑、import 的副作用。
  3. 用真实项目驱动：不要停留在练习册层面，尽快用 Python 做一个自己真正会使用的小工具。
  4. 读官方文档：Python 的官方文档质量极高，远超大多数语言。学会读它，比看任何二手教程都快。

总结 ​

找一个你可以记录笔记的地方（推荐在本仓库新建一个 notes/ 目录，用 Markdown 记录），写下今天的学习笔记，包括以下内容：

  • 日期，今天的学习总用时，今天学习的目标是什么，是否达成
  • 哪些东西今天了解得比较透彻，说说自己的理解
  • 哪些东西今天了解到了一些，还有哪些点需要后续继续深入阅读
  • 哪些东西今天学了之后还有很多疑问没有被解答，把问题记录下来，以待后续解决

当然，今天笔记最重要的事情是：

立 Flag，写下你参加 Python 学园的目标，能不能和我们一起坚持！
