Day 2 · Python 核心思维课 ​

前言 ​

今天的任务不写大项目，只做一件事：系统性排雷。Python 在缩进、相等性、真值、作用域和可变性上都有自己的语义。今天我们通过实验把它们逐个弄清；表格中的 JavaScript 对照只用于辅助理解。

课程目标 ​

  • 适应缩进即语法的世界观
  • 掌握 == vs is、None 与 Truthy/Falsy 的语义
  • 理解 Python 的可变/不可变类型
  • 亲手踩一遍"可变默认参数"的坑

阅读学习 ​

  • Python 官方教程第 3-4 章（非正式介绍、流程控制）
  • PEP 8 风格指南 —— 通读一遍即可，之后交给 ruff 强制执行
  • 可选的 JavaScript 差异对照（重点理解 Python 列）：
主题JavaScriptPython
空值undefined / null只有 None
相等==（宽松）/ ===（严格）==（值相等）/ is（同一对象）
假值0, '', null, undefined, NaN, false0, '', [], {}, (), None, False（空容器也是假！）
字符串拼接模板字符串 `a${b}`f-string f"a{b}"
常量const（运行时约束）约定俗成全大写 MAX_SIZE（无强制）
块级作用域let/const 有没有，只有函数/模块/类作用域
分号风格之争不需要
注释// /* */# 和 docstring """..."""

任务作业 ​

打开 Python REPL（终端输入 uv run python，或装个 uv add --dev ipython 体验更好），亲手验证并截图/记录以下实验：

  1. 缩进实验：故意写错缩进的 if 语句，观察 IndentationError
  2. is vs ==：执行 a = [1,2]; b = [1,2]; a == b; a is b，再执行 a = 256; b = 256; a is b 和 a = 257; b = 257; a is b，解释结果（提示：小整数缓存）
  3. 空容器假值：写 if []: print("yes") 和 if [0]: print("yes")，观察空列表与非空列表的真值差异
  4. 可变默认参数踩坑（本日最重要的实验）：
python
def append_to(item, box=[]):
    box.append(item)
    return box

print(append_to(1))  # [1]
print(append_to(2))  # 你以为是 [2]，实际是什么？为什么？

然后用正确写法（box=None + 函数体内初始化）修复它。

  1. 作用域实验：分别在函数中尝试修改模块级变量和嵌套函数的外层变量，理解 global 与 nonlocal 的作用

自测问题 ​

  • Python 如何表示“没有值”？访问不存在的 dict key 会发生什么？
  • 判断一个值是否为空列表，推荐写 if not lst 还是 if len(lst) == 0？为什么？
  • is 能用来比较字符串吗？为什么有时看起来"能"？
  • 函数默认参数在什么时候求值？（这是可变默认参数坑的根源）
  • Python 的 del 语句能删除哪些对象，它是否等于立即销毁对象？

总结 ​

记录今天的学习笔记（日期、用时、目标达成情况、透彻的点、待深入的点、疑问）。

今天的坑是被动踩的，明天开始就是主动写代码了。如果可变默认参数那个实验让你惊出一身冷汗，说明今天的课没白上。
