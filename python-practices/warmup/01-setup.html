Day 1 · 搭建现代化的 Python 开发环境 ​

前言 ​

Python 开发需要管理解释器版本、项目依赖与虚拟环境。Astral 公司出品的 uv（用 Rust 编写）把这些工作整合进一个工具，让我们可以一步到位搭好现代化开发环境。

课程目标 ​

  • 安装 uv，并理解它如何管理 Python、依赖与项目
  • 理解虚拟环境（venv）的作用与项目隔离机制
  • 初始化第一个 pyproject.toml 项目
  • 配置好编辑器，获得类型提示与代码跳转能力

阅读学习 ​

  • uv 官方文档 —— 重点看 Getting started 和 Projects 两节
  • Python 官方：虚拟环境入门
  • pyproject.toml 规范（PEP 621）
  • 可选的 Node 生态对照（不影响本课学习）：

任务作业 ​

现在我们来检验一下今天的学习情况，完成以下步骤：

  1. 安装 uv：curl -LsSf https://astral.sh/install.sh | sh（macOS 也可以 brew install uv）
  2. 用 uv python install 3.12 安装一个 Python 3.12，用 uv python list 确认
  3. 在任意空目录执行 uv init hello-python，观察它生成了哪些文件
  4. 打开生成的 pyproject.toml，理解 dependencies、requires-python 等字段的含义
  5. 执行 uv add rich，然后观察 pyproject.toml 和 uv.lock 的变化
  6. 修改 main.py，用 rich 打印一个彩色表格，执行 uv run main.py
  7. 在 VS Code 中安装 Python 扩展，将解释器指向项目的 .venv，确认类型提示和跳转正常工作

自测问题 ​

今天代码部分其实比较简单，主要是把环境理顺。回顾一下自己是否已经掌握以下概念：

  • 为什么 Python 强烈建议每个项目使用独立的虚拟环境？
  • uv run 和直接 python main.py 有什么区别？
  • uv.lock 应该提交到 Git 吗？为什么？
  • 如果不小心用了系统 Python 全局 pip install，会发生什么？
  • uvx ruff check 这行命令做了什么？
