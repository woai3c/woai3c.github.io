学园介绍

热爱

从第一行 Python 代码出发，在持续实践中感受语言与生态的魅力。

实践

以实践任务练习为驱动，让你知道每一个知识点的用武之地。每个任务都有明确的目标、步骤、自测问题，有挑战、有价值，也很有趣。

方法

不仅仅是知识，我们更重视方法。课程先讲清 Python 本身，再通过对照和实验帮助你建立理解。
