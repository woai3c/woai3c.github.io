Day 4 · FastAPI：现代 Python Web API 框架 ​

前言 ​

FastAPI 通过装饰器路由、类型驱动的依赖注入、自动生成的 OpenAPI 文档与原生异步支持，提供了一套现代 Web API 开发方式。今天用 FastAPI 从零实现一个 REST API。

课程目标 ​

  • 掌握路由、请求体、查询参数、路径参数的声明方式
  • 掌握依赖注入系统（Depends）——FastAPI 的灵魂
  • 掌握中间件、异常处理、后台任务
  • 理解自动 OpenAPI 文档的生成原理

阅读学习 ​

  • FastAPI 官方教程（文档质量极高，通读 Tutorial - User Guide）
  • 对照速览：
Express/NestJSFastAPI
app.get('/users/:id')@app.get("/users/{id}")
req.body + 手动校验/zod参数标注 body: UserCreate（pydantic 自动校验）
req.query.pagepage: int = 1（函数参数即查询参数）
middleware@app.middleware("http") 或中间件类

swagger 手动注解自动生成 /docs（Swagger UI）和 /redoc

任务作业 ​

  1. 迷你任务管理 API：实现一个 Task 管理 REST API：

    • POST /tasks（创建，pydantic 校验：title 必填 1-100 字符，priority 枚举 low/medium/high）
    • GET /tasks（支持 ?status=&priority=&page= 过滤与分页）
    • GET /tasks/{id}、PATCH /tasks/{id}、DELETE /tasks/{id}
    • 统一的 404/422 错误响应格式（自定义 exception handler）
    • 数据先用内存 dict 存储

  2. 依赖注入体验：把"获取当前用户"实现为依赖：

python
async def get_current_user(token: str = Header(...)) -> User: ...

@app.get("/me")
async def me(user: User = Depends(get_current_user)): ...

观察 Depends 如何解析、执行并注入依赖，再写一个带参数的依赖工厂（如分页参数依赖）。

  1. 异步 vs 同步路由：写一个 async def 路由调用 httpx 请求外部 API，一个 def 路由调用同步 time.sleep，压测对比并发能力（可用 uv run python -m http.server 配合 ab 或 wrk，或简单用 asyncio 并发请求计时）。

  2. 中间件：写一个请求日志中间件（记录方法、路径、耗时），再写一个请求 ID 中间件（生成 UUID 注入响应头 X-Request-ID）。

  3. 欣赏文档：启动后访问 http://localhost:8000/docs，在 Swagger UI 里直接调用你的 API，观察路由与数据模型如何自动转换为 OpenAPI 文档。

自测问题 ​

  • FastAPI 如何用类型标注同时完成"校验 + 文档生成"？背后是哪个库？
  • def 路由和 async def 路由分别在哪里执行？在 async def 里调用阻塞函数会发生什么？
  • Depends 的依赖可以嵌套吗？依赖的缓存策略是怎样的（同一请求内）？
  • FastAPI 和 Flask、Django 的定位差异是什么？
  • 如何把 FastAPI 应用跑在生产环境？（uvicorn / gunicorn + uvicorn workers）
